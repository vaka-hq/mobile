# Material Symbols

Filled (`FILL@1`) Material Symbols Outlined icons (weight 400, 24px) for selected navigation
destinations and primary playback controls, bundled locally because `@expo/material-symbols`
ships only the unfilled style. Generated with its `add-material-symbols --fill` CLI.

License: Apache 2.0, https://github.com/google/material-design-icons/blob/master/LICENSE

`skip_back_*` and `skip_forward_*` combine the `replay` and `forward_media` arrows with Material's
blocky digits (4 and 6 drawn on the same grid) for every skip interval. They are generated by
`vp run icons:skip`.
